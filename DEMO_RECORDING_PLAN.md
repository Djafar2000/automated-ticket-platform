# Demo Recording Plan

Suggested duration: about 5 minutes

## Recommended sequence

1. Show the login page and briefly explain the project.
2. Register a demo account.
3. Log in and show the user dashboard.
4. Enter ticket preferences and save them.
5. Start a purchase session.
6. Wait for the status progression to complete.
7. Show the resulting transaction in the dashboard.
8. Open the admin view and show:
   - recent sessions
   - alerts
   - transaction history
9. Conclude with key limitations:
   - simulated workflow
   - no live ticketing integration
   - designed as a proof-of-concept build

## Key message

The core project idea works end-to-end: a user can configure a ticket request, run a guided automated attempt, and the platform records and monitors the outcome through both the user and admin sides of the system.
